# Web_Programming
3-1학기 웹 프로그래밍_ 개인 소개 웹 페이지 프로젝트 

---

## 주요 기능

- **가로 스크롤 내비게이션** — 메뉴·좌우 버튼으로 화면 단위 이동
- **현재 위치 표시** — 스크롤에 따라 활성 메뉴와 커스텀 스크롤바가 자동 갱신
- **My Story 탭 이동** — 사이드바 목차 클릭으로 섹션 이동
- **프로젝트 상세 모달** — 카드 클릭 시 기술 스택·설명·GitHub 링크 표시
- **Issue 페이지 스냅 스크롤** — 세로 스크롤 시 한 페이지씩 정렬
- **반응형 대응** — 좁은 화면(760px 이하)용 레이아웃 적용

---

## 기술 스택

| 구분 | 내용 |
|------|------|
| Markup | HTML5 (시맨틱 태그, ARIA) |
| Style | CSS3 (Flexbox, Grid, scroll-snap, 커스텀 스크롤바, 미디어 쿼리) |
| Script | Vanilla JavaScript (ES6+) — DOM 조작, 모달, Scroll Spy |
| 협업 | Git / GitHub |
